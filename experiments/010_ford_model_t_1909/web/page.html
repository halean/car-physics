About this simulation

The physics runs in your browser on MuJoCo's official WebAssembly build, the same engine version as the Python validation. The model is the validated car file: the same bodies, joints, springs, tyres and engine. On the bump course with design settings, this port reproduces the Python run to four decimal places (seat RMS 0.218 g, 76.94 m in 13 s).

  • Settings you change here are for exploring. Only the design values have passed the repository's checks.
  • The tyres are stiffer than a real 30 × 3½ clincher, so wheels lift off more than they would on a real car.
  • The springs are linear, with no interleaf friction or wind-up; damping stands in for both.

Run it locally from the repository: .venv/bin/python experiments/010_ford_model_t_1909/web/build.py, then python3 -m http.server -d experiments/010_ford_model_t_1909/output/web 8000 and open localhost:8000/local.html.
